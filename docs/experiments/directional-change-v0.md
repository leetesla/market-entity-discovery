# Directional Change V0

This experiment adds a second market representation alongside the existing 5m multivariate-bar / mSTUMP baseline.

## Question

Instead of asking:

> Which fixed-length 5m windows look alike?

ask:

> What market structure appears when observations are generated by meaningful price reversals rather than by the wall clock?

## Representation

For reversal threshold delta:

- **UPTURN** is confirmed when price rises at least delta from the running low.
- **DOWNTURN** is confirmed when price falls at least delta from the running high.
- After confirmation, the regime state is +1 (UPTURN) or -1 (DOWNTURN) until the next opposite confirmation.

The implementation stores both:

1. **extremum time** — where the turning extreme ultimately occurred;
2. **confirmation time** — when the reversal became knowable causally.

This distinction is mandatory. A historical pivot must never be treated as available before its confirmation.

## Multi-scale state

The first experiment uses:

- 0.25%
- 0.5%
- 1%
- 2%
- 4%

At every timestamp, the market can therefore have an intrinsic state such as:

```text
U U D D D
```

meaning the small scales are in an upward post-UPTURN regime while larger scales remain downward.

These cross-scale state vectors are candidate **market states**, not trading signals.

## Data

For Directional Change V0 we use BTCUSDT USD-M futures **1m close**, not 5m, because an event-driven representation should not throw away more intrabar path information than necessary for the first test.

The initial reproducible smoke run uses Binance Vision monthly data for January 2025.

## Validation questions

1. How many events survive at each threshold?
2. How does event duration scale as threshold increases?
3. What multi-scale states recur most often?
4. Which state-to-state transitions recur?
5. Are those state distributions stable across later months?
6. Do the same intrinsic states appear in ETH or other markets?
7. Only after stability checks: do particular states/transitions change future outcome distributions?

## What this is not

This is not yet an attempt to trade Directional Change events. It is a test of whether event/intrinsic-time representation exposes stable entities and transitions that fixed 5m windows obscure.
